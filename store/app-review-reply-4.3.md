Hello,

1. Auto Browse is an iPhone browser with an AI agent that does web tasks for the user (compare prices, collect data into a CSV, fill multi-step forms). The agent clicks, types and scrolls in a real tab while the user watches live and can take over at any time. It solves multi-step web chores that are slow on a phone. Passwords go into a secure card and are never sent to the AI.

2. Existing ChatGPT subscribers (freelancers, small businesses, shoppers) who do repetitive research or admin on the web from their phone. They sign in with their own ChatGPT account.

3. ChatGPT's agent runs in a remote cloud browser. Desktop AI browsers have no agent on iPhone. Safari and Chrome have no agent. Auto Browse acts in the user's own on-device tabs, with tabs that run in parallel, a secret vault the AI cannot read, question cards, and export to files.

4. I tested it myself through TestFlight, across 19 builds. Changes made from that testing: login without an http warning, a live split view of the agent, no 12-step limit, a keyboard fix, tabs with one chat each, a confirmation before opening other apps, CSV export, the secure password card, and pause/resume when the phone locks.
